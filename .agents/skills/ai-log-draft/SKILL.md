# Drafting the AI log entry

**Never write docs/ai-log.md: give the draft in the chat.** The human
corrects it and writes it in the file.

Copy this checklist into your reply and tick it as you go:

- [ ] 1. Collect from this session: the files you generated and the tool
         you are, what the human changed or rewrote, the commands and
         tests that ran, the proposals refused, the reasons given.
- [ ] 2. Write the draft in the chat, in this format:

         ## YYYY-MM-DD: <task>
         - Generated by AI: ...
         - Written by me: ...
         - Verified by me: ...
         - Verified by tests: ...
         - Decided: ...

- [ ] 3. Verified by me: only what the human said they checked by hand.
         Nothing said → [what did you check yourself?]. Test results
         go in Verified by tests, never here.
- [ ] 4. Decided: each decision with the human's reason. No reason in
         the chat → [why?].
- [ ] 5. End with: "Correct it, then write it in docs/ai-log.md yourself."
